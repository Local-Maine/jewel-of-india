# The Jewel of India website

Static site files for The Jewel of India.

## Menu updates

Edit `menu-data.js` to update dishes, descriptions, prices, locations, phone numbers, or hours.

Each menu item uses this format:

```js
["Dish Name", "18.95", "Short description."]
```

The website menu and the printable menu both use the same data file.

## GitHub Pages

1. Upload the files to the root of the repository.
2. Open **Settings > Pages**.
3. Choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save the changes.

The site does not include a `CNAME` file.
